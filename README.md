## Описание проекта
Автоматизированное тестирование REST API учебного сервиса **Stellar Burgers** (`https://stellarburgers.education-services.ru/`).

### Покрытая функциональность:
1. **Создание пользователя** (`POST /api/auth/register`) - создание уникального пользователя, проверка ошибки при создании уже зарегистрированного пользователя и при отсутствии одного из обязательных полей (`email`, `password`, `name`).
2. **Логин пользователя** (`POST /api/auth/login`) - авторизация под существующим пользователем, проверка ошибки при передаче неверного логина и/или пароля.
3. **Создание заказа** (`POST /api/orders`) - создание заказа с авторизацией и без авторизации с валидными ингредиентами, проверка ошибки при создании заказа без ингредиентов и ошибки `500` при передаче неверного хеша ингредиентов.

## Архитектура проекта
* `data.py` - URL-адреса эндпоинтов, ожидаемые сообщения об ошибках и тестовые константы.
* `helpers.py` - генерация тестовых данных пользователя с использованием `Faker`.
* `user_methods.py` и `order_methods.py` - классы с HTTP-методами, размеченные шагами `@allure.step`.
* `conftest.py` - фикстуры создания/удаления тестовых пользователей (`yield` teardown) и получения актуальных ингредиентов.
* `tests/` - тестовые классы, разделённые по проверяемым ручкам (`test_create_user.py`, `test_login_user.py`, `test_create_order.py`).
* `allure_results/` - артефакты для генерации отчёта Allure.
* `requirements.txt` - список зависимостей проекта.
* `.gitignore` - исключение кэша и виртуального окружения.
